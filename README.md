# ZEPHYR

행글라이더를 타고 노을 진 구름바다 위를 나는 힐링 비행 게임이에요. 휴대폰과 PC 브라우저에서 돌아가요.

현재 **1단계**: 1인칭 비행 감각과 카메라, 구름과 떠 있는 섬, 상승기류

## 맵

시작 화면에서 고를 수 있어요 (마지막으로 고른 맵을 기억해요).

- **노을 운해**: 노을 진 구름바다 위 떠 있는 섬들
- **그랜드 캐니언**: 실제 그랜드 캐니언의 지층 순서대로 깎인 계단식 협곡과 콜로라도 강, 고원의 향나무 숲.
  본 협곡 북쪽에서 갈라져 말굽처럼 돌아 나오는 **좁은 협곡 코스**에는 바위 기둥과 자연 아치가 있어요.

## 바로 하기

**https://kimarthur815-collab.github.io/ZEPHYR/** 에 들어가면 바로 실행돼요.

저장소를 받았다면 맨 위 `index.html`을 브라우저로 열어도 돼요.

## 조작

휴대폰은 시작 화면에서 **세로 모드** 또는 **가로 모드**를 누르면 바로 전체화면으로 시작해요. 아이폰은 공유 → 홈 화면에 추가로 열면 전체화면이 돼요.

폰의 **자동 회전은 꺼두는 걸 추천**해요. 가로 모드를 고르면 게임이 알아서 옆으로 누워서 나오고, 기울여도 화면이 돌아가지 않아요.

| | PC | 휴대폰 |
|---|---|---|
| 방향 | A / D (← / →) | 폰을 핸들처럼 기울이기 (안 되면 왼쪽 화면 드래그 좌우) |
| 내려가기(빨라짐) / 올라가기(느려짐) | W / S (↑ / ↓) | 폰 앞으로 숙이기 / 뒤로 젖히기 (안 되면 왼쪽 화면 드래그 위 / 아래) |
| 둘러보기 | 마우스 드래그 | 오른쪽 화면 드래그 |
| 소리 켜기 / 끄기 | | 오른쪽 위 🔊 버튼 |
| 수평 다시 맞추기 | | 화면 두 번 탭 (조금 기운 채 가만히 있으면 자동으로도 맞춰져요) |

빛나는 바람 기둥(상승기류) 안을 빙글빙글 돌면 높이 올라가요. 섬에 부딪혀도 게임오버는 없고, 구름바다까지 떨어지면 다시 떠올라요.

## 수정하기

코드 원본은 `src/`에 있어요 (`main.js`가 게임, `index.html`이 화면). 고친 뒤 다시 묶으면 맨 위 `index.html`이 새로 만들어져요.

```
npm install
npm run build
```
