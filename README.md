# ZEPHYR

행글라이더를 타고 노을 진 구름바다 위를 나는 힐링 비행 게임이에요. 휴대폰과 PC 브라우저에서 돌아가요.

현재 **1단계**: 1인칭 비행 감각과 카메라, 구름과 떠 있는 섬, 상승기류

## 바로 하기

**https://kimarthur815-collab.github.io/zephyr/** 에 들어가면 바로 실행돼요.

저장소를 받았다면 맨 위 `index.html`을 브라우저로 열어도 돼요.

## 조작

| | PC | 휴대폰 |
|---|---|---|
| 방향 | A / D (← / →) | 왼쪽 화면 드래그 좌우 |
| 빨라짐 / 느려짐 | W / S (↑ / ↓) | 왼쪽 화면 드래그 위 / 아래 |
| 둘러보기 | 마우스 드래그 | 오른쪽 화면 드래그 |
| 시점 바꾸기 | V | 오른쪽 위 시점 버튼 |

빛나는 바람 기둥(상승기류) 안을 빙글빙글 돌면 높이 올라가요. 섬에 부딪혀도 게임오버는 없고, 구름바다까지 떨어지면 다시 떠올라요.

## 수정하기

코드 원본은 `src/`에 있어요 (`main.js`가 게임, `index.html`이 화면). 고친 뒤 다시 묶으면 맨 위 `index.html`이 새로 만들어져요.

```
npm install
npm run build
```
